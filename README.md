# 🏥 Hospital Patient Records Analysis

An end-to-end Data Analytics project focused on Hospital Patient Records using Python. This project performs comprehensive Exploratory Data Analysis (EDA), data preprocessing, feature engineering, statistical analysis, and business insights to understand healthcare trends and patient behavior.

---

## 📌 Project Objective

The primary objective of this project is to analyze hospital patient records and extract meaningful insights that can help healthcare organizations improve patient care, operational efficiency, and decision-making.

The project follows a structured Data Analytics workflow used by professional Data Analysts.

---

## 📊 Project Workflow

### 1. Data Collection
- Imported Hospital Patient Records dataset
- Loaded data using Pandas

### 2. Data Understanding
- Dataset Shape
- Data Types
- Column Information
- Missing Values
- Duplicate Records

### 3. Data Cleaning
- Handling Missing Values
- Removing Duplicates
- Data Type Conversion
- Data Consistency Checks

### 4. Feature Engineering
- Created meaningful derived features
- Improved dataset usability

### 5. Exploratory Data Analysis (EDA)

Performed detailed analysis including:

- Descriptive Statistics
- Univariate Analysis
- Bivariate Analysis
- Multivariate Analysis
- Correlation Analysis
- Outlier Detection
- Distribution Analysis
- Category-wise Analysis
